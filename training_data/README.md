## 📂 Detailed Folder Structure

The `training_data/` directory is divided into three main folders, each corresponding to a specific type of atomic configuration:

```
training_data/
├── random_disp_0.3A/
├── shear_strain/
└── uniaxial_strain/
```

---

## 🔹 1. `random_disp_0.3A/` — Rattled Structures

This folder contains configurations generated by applying **random atomic displacements** (up to 0.3 Å) to equilibrium structures.

### 📁 Files

```text
Bi2Te3.json
Sb2Te3.json
BiTeSb_20.json
BiTeSb_40.json
BiTeSb_60.json
BiTeSb_80.json
```

### ⚙️ Details

- Each file corresponds to one composition
- Each file contains **200 configurations**
- Atomic positions are randomly displaced
- Lattice vectors remain fixed

---

## 🔹 2. `shear_strain/` — Shear Deformations

This folder contains configurations with **applied shear strain**, with and without atomic perturbations.

### 📌 Filename Pattern

```text
<composition>_<strain>_pct_perturb_<amplitude>_ptb_lattice.json
```

### 📖 Meaning of Terms

- `<composition>` → e.g., `Bi2Te3`, `BiSbTe_40`
- `<strain>` → `1` or `3` (% shear strain)
- `perturb_0` → no atomic displacement
- `perturb_0.3` → random displacement up to 0.3 Å

---

### 📊 Categories

#### (a) No Atomic Perturbation

```text
*_1_pct_perturb_0_ptb_lattice.json
*_3_pct_perturb_0_ptb_lattice.json
```

- Pure shear deformation
- Atomic positions scaled affinely

#### (b) With Atomic Perturbation

```text
*_1_pct_perturb_0.3_ptb_lattice.json
*_3_pct_perturb_0.3_ptb_lattice.json
```

- Shear strain + random atomic displacement
- Mimics realistic thermal disorder

### 📈 Per Composition

- 50 configurations → 1% shear
- 50 configurations → 3% shear

**Total:** 100 (no perturbation) + 100 (with perturbation)

---

## 🔹 3. `uniaxial_strain/` — Directional Strain

This folder contains configurations generated by applying **uniaxial strain along Cartesian directions**.

### 📁 Files

```text
Bi2Te3_X.json
Bi2Te3_Y.json
Bi2Te3_Z.json
...
BiSbTe_20_pct_X.json
...
Sb2Te3_Z.json
```

### 📖 Meaning

- `_X`, `_Y`, `_Z` → strain applied along that direction

Each file contains **11 strain points**:

```text
-10%, -8%, -6%, -4%, -2%, 0%, +2%, +4%, +6%, +8%, +10%
```

### ⚙️ Details

- Only one lattice vector is scaled
- Other two directions remain fixed
- No atomic perturbation

### 📈 Per Composition

11 (X) + 11 (Y) + 11 (Z) = **33 configurations**

---

## 🧾 Naming Convention Summary

| Pattern            | Meaning                       |
| ------------------ | ----------------------------- |
| `random_disp_0.3A` | Random displacement (≤ 0.3 Å) |
| `1_pct` / `3_pct`  | Shear strain magnitude        |
| `perturb_0`        | No atomic displacement        |
| `perturb_0.3`      | With atomic displacement      |
| `_X`, `_Y`, `_Z`   | Uniaxial strain direction     |

---

## 🧠 Important Notes

All configurations:

- Originate from **DFT-relaxed equilibrium structures**
- Maintain consistent composition-wise sampling
- Are designed to capture:
  - Elastic response
  - Anharmonic effects
  - Disorder under strain
